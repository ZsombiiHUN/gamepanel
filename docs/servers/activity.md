# Activity

The **Activity** tab is the server's history in plain words: who restarted it, uploaded what, changed which setting, connected over SFTP. It is searchable. You need the `activity.read` permission (owners and admins always have it).

Each entry shows when it happened, who did it, and what. **Client addresses are shown only to the owner** (and admins), so subusers cannot see each other's addresses.

Admins see the same events for the whole panel, plus sign-ins and account changes, in the [audit log](/admin/audit-log).

Entries are kept indefinitely for now.
